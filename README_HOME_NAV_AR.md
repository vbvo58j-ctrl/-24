# تحديث واجهة بلوساب

- أصبح شريط التنقل السفلي يتكون من أربع واجهات فقط: المحادثات، المنشورات، القصص، وملفي.
- الإعدادات موجودة داخل واجهة «ملفي» ولا توجد كواجهة مستقلة.
- شاشة المحادثات هي الواجهة الافتراضية عند فتح التطبيق.
- أضيفت أعلى قائمة المحادثات ثلاثة اختصارات صغيرة: الاشتراك، محادثة جديدة، والبحث عن مستخدمين.
- الاشتراك يعرض رسالة توضيحية لأن نظام الاشتراكات غير موجود في المشروع حاليًا.
- اختصارا «محادثة جديدة» و«بحث عن مستخدمين» يستخدمان حاليًا آلية اكتشاف مستخدمي بلوساب القريبين عبر البلوتوث.

ملاحظة: تم تحديث ملفات المصدر وحزمة ZIP والتحقق من سلامة الأرشيف، لكن لم يتم تشغيل Flutter analyze أو بناء APK في هذه البيئة لعدم توفر Flutter SDK.


## شريط المحادثات والاشتراكات
- اختصارات الاشتراك والمحادثة الجديدة والبحث عن المستخدمين أصبحت مستطيلات أفقية صغيرة أعلى قائمة المحادثات.
- تمت إضافة شاشة إدارة خطط الاشتراك وحفظ اختيار الخطة محليًا. هذا ليس اشتراكًا مدفوعًا حقيقيًا: لا يوجد دفع أو تحقق من الخادم، ويلزم ربط مزود دفع وخادم آمن قبل تحصيل أي أموال أو ادعاء تفعيل اشتراك.
