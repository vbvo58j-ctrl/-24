# ميزة الستوري في بلوساب

- أضيف شريط قصص أعلى شاشة المجتمعات.
- إنشاء ستوري من المعرض أو الكاميرا مع تعليق اختياري.
- عرض قصصي ملء الشاشة مع شريط تقدم وإغلاق وحذف.
- تنتهي صلاحية القصة بعد 24 ساعة وتُحذف من التخزين المحلي عند إعادة تحميل القصص.
- تخزّن القصص على الجهاز الحالي باستخدام SharedPreferences وملفات داخل مجلد التطبيق.

مهم: هذه نسخة واجهة/تخزين محلي أولي. القصص لا تُرسل إلى الهواتف الأخرى ولا تظهر للمستخدمين الآخرين بعد؛ يلزم تصميم بروتوكول نقل/مزامنة آمن فوق خدمة الاتصال الحالية أو خادم حتى تعمل القصص بين المستخدمين مثل Instagram.

لم يُجرَ اختبار بناء Flutter في هذه البيئة لأن Flutter SDK غير متاح.
