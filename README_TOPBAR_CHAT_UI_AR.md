# تحديث الشريط العلوي وواجهة المحادثات

## الشريط العلوي
- شريط واحد ثابت أعلى الواجهات الأربع، بلون سطح الثيم الحالي.
- إزالة الظل والاكتفاء بفاصل خفيف متوافق مع الثيم.
- لون زر الاتصال يتبع اللون الأساسي للثيم، ولون الإشعارات يتبع لون النص الثانوي.
- زر الاتصال يواصل تشغيل الإجراء الحالي بحسب وضع Bluetooth أو Wi-Fi، وزر الإشعارات يفتح نافذة الإرشادات الحالية.

## واجهة المحادثات
- جعل بطاقة الترحيب وأزرار الإجراءات في قسم ثابت خارج قائمة المحادثات القابلة للتمرير.
- تصغير الأزرار المستطيلة إلى ارتفاع 30 وعرض 116 تقريبًا، مع مسافات ضيقة ومنظمة وتمرير أفقي عند الحاجة.
- جعل قائمة المحادثات والمجتمعات وحدها قابلة للتمرير والسحب للتحديث.
- استخدام ألوان الثيم الفاتح/الداكن للنصوص والخلفيات والحدود، وتقليل الزخارف والظلال.

ملاحظة: لم يتوفر Flutter SDK في بيئة التعديل، لذلك لم يُنفذ `flutter analyze` أو بناء APK. يجب اختبار المشروع في بيئة Flutter قبل النشر.
