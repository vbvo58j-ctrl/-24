# معاينة محادثة المطور

تحتوي شاشة المحادثة التجريبية على قائمة خيارات وإعدادات مستقلة للمعاينة: حجم الخط، خلفية المحادثة، إظهار الوقت، ضغط الفقاعات، علامات القراءة، الرسائل ذاتية الاختفاء (توضيح فقط)، كتم الإشعارات، تثبيت المحادثة، الحظر وفك الحظر، ومسح محتوى المحادثة. كما توجد عناصر مرفقات تجريبية وبحث داخل الرسائل.

جميع هذه العناصر تعمل محليًا داخل شاشة المعاينة ولا ترسل رسائل أو ملفات فعلية، ولا تغيّر إعدادات المحادثات الحقيقية. يجب بناء المشروع وتجربته في بيئة Flutter قبل اعتماد APK؛ لم يتوفر Flutter/Dart لإجراء بناء كامل في بيئة التحرير.
