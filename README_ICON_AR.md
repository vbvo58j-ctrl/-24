# أيقونة تطبيق بلوساب

تم إعداد الصورة المرفقة كأيقونة Android للتطبيق، مع ملفات الدقة المختلفة وأيقونة Adaptive لأجهزة Android 8 وما بعده. تم تحديث `android/app/src/main/AndroidManifest.xml` ليستخدم `@mipmap/ic_launcher`.

للتأكد من ظهور التغيير، ابنِ التطبيق وثبّت النسخة الجديدة. لم أتمكن من تشغيل `flutter build apk` في بيئة العمل لعدم توفر Flutter/Dart هنا.
