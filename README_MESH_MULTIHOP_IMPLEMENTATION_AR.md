# بلوساب — تنفيذ شبكة Mesh متعددة القفزات (نسخة دمج أولي)

## ما يفعله هذا الإصدار
- يتيح اكتشاف الأجهزة على شبكة Wi‑Fi/LAN المحلية عبر UDP، وتبادل الحزم عبر TCP.
- يستخدم خدمة Bluetooth Classic الموجودة في المشروع كمسار نقل إضافي عندما تكون الخدمة والأجهزة متصلة.
- يضع الرسائل المسموح بترحيلها في طابور دائم داخل مساحة التطبيق، مع إزالة التكرار بواسطة معرف الرسالة.
- يضيف مسار الترحيل وعدد القفزات، ويوقف الرسائل التي تجاوزت 5 قفزات أو عمر 24 ساعة أو التي مرّت بالجهاز نفسه.
- يعيد المحاولة عند اكتشاف جهاز أو اتصال جديد، مع حدود لحجم الطابور وسجل الرسائل التي شوهدت.

## حدود مهمة — لا تعتبرها شبكة Mesh مكتملة بعد
- اكتشاف UDP الحالي يعمل ضمن شبكة محلية/نطاق بث متاح؛ لا ينشئ Wi‑Fi Direct أو نقطة اتصال تلقائيًا ولا يستطيع وحده نقل البيانات بين شبكات فرعية منفصلة.
- Bluetooth Classic لا يضمن أن كل هاتف متصل بكل الهواتف الأخرى؛ الترحيل يعتمد على اتصالات النقل المتاحة فعليًا.
- الترحيل مرتبط بدورة حياة شاشة الدردشة/الخدمة الحالية، وليس خدمة Android دائمة مضمونة بعد إغلاق التطبيق أو قتله النظام.
- لا يوجد في هذه النسخة تشفير طرف إلى طرف أو مصادقة تشفيرية لهوية المرسل. لا تستخدمها لإرسال معلومات حساسة.
- آلية ACK عبر عدة وسطاء وإدارة ازدحام الراديو تحتاج إلى اختبارات ميدانية وإكمال إضافي. نجاح كتابة الحزمة في socket لا يعني وصولها إلى المستلم.
- قيود Android على الأذونات، العمل بالخلفية، البطارية، Wi‑Fi Direct والبلوتوث تختلف حسب إصدار النظام والشركة المصنّعة.

## خطة التحقق المطلوبة قبل اعتمادها إنتاجيًا
1. بناء APK بواسطة إصدار Flutter/Dart المعتمد للمشروع.
2. اختبار 3 أجهزة على الأقل: A → B → C مع إيقاف الاتصال المباشر بين A وC.
3. اختبار إعادة تشغيل وسيط، وفقدان الاتصال وعودته، وتكرار بث الحزمة، وانتهاء TTL وحد القفزات.
4. اختبار Android 12 وما بعده للأذونات، وحالات الشاشة المغلقة وتوفير الطاقة.
5. إضافة/اختبار Wi‑Fi Direct فعلي أو نقل محلي مناسب إذا كان المطلوب أن تعمل الشبكة دون راوتر أو نقطة اتصال مشتركة، وإضافة تشفير طرف إلى طرف قبل الاستخدام الحقيقي.

## نتيجة التحقق في بيئة إعداد هذه الحزمة
تم فحص ملفات ZIP وسلامة أرشيف الإخراج فقط. لم تتوفر أداة Flutter/Dart هنا؛ لم يُنفذ `flutter analyze` أو بناء APK ولم يجر اختبار أجهزة فعلية. هذه نسخة دمج أولي قابلة للمراجعة وليست شهادة اكتمال للشبكة المطلوبة.
