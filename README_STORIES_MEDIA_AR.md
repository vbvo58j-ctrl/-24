# تحديث القصص المصورة والفيديو في بلوساب

- إضافة اختيار صورة أو فيديو من المعرض، أو التقاط صورة/فيديو بالكاميرا.
- ضغط الصور عند الاختيار، ومحاولة ضغط الفيديو بجودة متوسطة قبل حفظه.
- تشغيل الفيديو تلقائيًا عند فتح الحالة، مع شريط تقدم وزر إيقاف/تشغيل.
- إضافة زر «تحميل الحالة» لحفظ نسخة داخل مجلد بيانات بلوساب `blousab_saved_statuses`.
- استمرار انتهاء الحالة المنشورة بعد 24 ساعة.

## حدود مهمة

هذه الإضافة تحسّن إنشاء الوسائط وعرضها وحفظها على الجهاز الحالي، لكنها **لا تنشئ مزامنة بين الأجهزة** ولا تنقل الحالات تلقائيًا إلى مستخدمين آخرين. ذلك يتطلب ربط نقل الوسائط عبر خدمة الاتصال وبوابة تحقق من قبول الصداقة/المصادقة والحظر قبل إرسال كل حالة. لا تدّعي الواجهة أن الحالة وصلت إلى أجهزة أخرى.

لم يتم تشغيل `flutter pub get` أو بناء APK في بيئة التعديل لعدم توفر Flutter SDK هنا؛ يلزم اختبار الحزم والبناء على جهاز تطوير Flutter قبل النشر.
