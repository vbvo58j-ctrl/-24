# المنشورات العامة القريبة في بلوساب

- تدعم صفحة المنشورات إنشاء منشور نصي أو صورة أو فيديو، والهاشتاجات والإعجاب والتعليقات وحذف منشورك والإبلاغ محليًا.
- تحفظ المنشورات والوسائط محليًا. وتتم مزامنتها تلقائيًا مع الأجهزة القريبة المتصلة عند فتح الخلاصة أو اكتشاف اتصال جديد، مع مصالحة دورية لاستعادة ما فاته الجهاز.
- تستخدم النسخة الحالية Wi-Fi Aware Data Path على الأجهزة الداعمة (Android 10/API 29 أو أحدث مع دعم العتاد) لنقل البيانات مباشرة دون راوتر أو نقطة اتصال، مع استخدام LAN كمسار بديل عندما تتوفر شبكة محلية.
- تنقل الصور والفيديوهات في حاوية GZIP مجزأة إلى إطارات، ثم تجمع وتفك تلقائيًا على الجهاز المستلم لتظهر بصيغتها الأصلية.
- تفاصيل التنفيذ والحدود والاختبارات المطلوبة موثقة في `README_PART13_PUBLIC_FEED_SYNC_AR.md`.

## الحدود
- المزامنة هنا بين الأجهزة القريبة التي اكتشفت بعضها وأنشأت قناة بيانات. لا توجد خدمة سحابية أو مزامنة عبر المدن أو الإنترنت.
- لا تدعم جميع هواتف Android ميزة Wi-Fi Aware؛ الأجهزة غير الداعمة تعتمد على LAN عندما تكون على الشبكة المحلية نفسها؛ نقل المنشورات عبر Bluetooth لم يُربط بعد.
- يجب اختبار قناة Wi-Fi Aware Data Path فعليًا على هاتفين متوافقين؛ لم يتم بناء APK أو تشغيل flutter analyze/test في بيئة التعديل لعدم توفر Flutter/Android SDK.
