# صلاحيات بلوساب

أضيفت في الإعدادات بطاقة «صلاحيات البلوتوث وWi-Fi والظهور فوق التطبيقات». منها يطلب التطبيق صلاحيات Bluetooth Scan/Connect/Advertise وNearby Wi-Fi عند دعم النظام، ويطلب إذن الظهور فوق التطبيقات الأخرى عبر شاشة إعدادات أندرويد الخاصة.

تنبيه: إذن SYSTEM_ALERT_WINDOW صلاحية خاصة يمنحها المستخدم يدويًا من إعدادات النظام. أندرويد لا يوفر صلاحية عامة تسمح لكل التطبيقات بتشغيل نقطة اتصال Wi-Fi تلقائيًا على جميع الأجهزة والإصدارات؛ قد يحتاج المستخدم لتشغيلها يدويًا.

لم يتم بناء APK أو اختبار الصلاحيات على جهاز فعلي في بيئة العمل هذه.
