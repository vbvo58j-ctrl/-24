# بلوساب — الجزء السابع: توحيد الثيم

## التعديلات
- إنشاء دالة موحدة `buildBlousabTheme` للثيم الفاتح والداكن، تشمل ألوان الخلفية والسطح والنصوص والحدود وحقول الكتابة والبطاقات والنوافذ والقوائم وأشرطة التطبيق.
- إزالة ارتفاع الشريط العلوي وتأثير `surfaceTint` وتوحيد لون الشريط مع الخلفية.
- استخدام الثيم الموحد في واجهة التطبيق الرئيسية وفي نافذة الإعدادات، مع معاينة التغيير داخل الإعدادات عند اختيار مظهر مختلف.
- الإبقاء على حفظ اختيار المظهر عبر `SharedPreferences` بالمفتاح الحالي `wasl_background`، وإعادة تطبيقه عند تحميل الإعدادات عند تشغيل التطبيق.
- جعل خلفية المحادثة الافتراضية/البيضاء تتكيف مع الثيم الداكن بدل فرض خلفية بيضاء، مع الحفاظ على اختيار الخلفية المخصصة.
- إضافة الثيمين الفاتح والداكن إلى `MaterialApp` كقيم احتياطية للصفحات التي لا تقع داخل غلاف التطبيق.

## التحقق والقيود
- لم يتوفر Flutter/Dart في بيئة التحرير؛ لم يتم تشغيل `flutter analyze` أو بناء APK.
- لم يتم اختبار كل شاشة على جهاز Android فعلي. بعض الشاشات/العناصر التي تستخدم ألوانًا ثابتة مقصودة (مثل عارض الحالة والفيديو وألعاب الطاولة) تبقى داكنة/ملونة عمدًا؛ ينبغي مراجعتها بصريًا على الجهاز.
- اختيار «افتراضي» يعامل كالمظهر الفاتح داخل التطبيق؛ أما `ThemeMode.system` فهو قيمة احتياطية خارج غلاف التطبيق.
